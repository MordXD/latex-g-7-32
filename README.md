# Cloud-Native сервис компиляции LaTeX

Микросервисная архитектура корпоративного уровня для асинхронной генерации PDF-документов на основе LaTeX-шаблонов (ГОСТ 7-32).

## Архитектура и возможности

Проект реализует масштабируемую stateless-архитектуру, рассчитанную на развёртывание в Kubernetes.

### Основные компоненты
* **API Gateway (FastAPI):** Stateless REST- и WebSocket-API. Обрабатывает запросы, аутентификацию и стриминг прогресса в реальном времени через Redis Pub/Sub.
* **Worker (Python/FastStream):** Декуплированные consumer’ы, слушающие RabbitMQ. Выполняют CPU-интенсивную компиляцию с потоковой обработкой логов.
* **Управление состоянием (Redis):** Хранит статус задач (Pending, Processing, Success) и обеспечивает Pub/Sub для логов в реальном времени.
* **Хранилище (S3/MinIO):** Надёжное долговременное хранение сгенерированных PDF и логов.
* **Брокер (RabbitMQ):** Гарантирует доставку и распределение задач.

### Ключевые оптимизации
1. **Сокращение Docker-образа на 70%:**
   * Переход с `texlive-full` (4GB+) на кастомную сборку Alpine/Debian (~800MB).
   * Использование multi-stage сборок.
   * Установка только необходимых TeX-пакетов через `tlmgr`.
2. **Наблюдаемость в реальном времени:**
   * Метрики **Prometheus** для пропускной способности, задержек и ошибок.
   * **Логи в реальном времени:** пользователь видит прогресс компиляции постранично через WebSocket.
3. **Готовность к cloud-native:**
   * Полностью stateless-контейнеры.
   * Готово к Horizontal Pod Autoscaling (HPA).
   * Конфигурация через ConfigMaps и Secrets Kubernetes.

## Технологический стек

* **Язык:** Python 3.11
* **Фреймворки:** FastAPI, Uvicorn, FastStream
* **Инфраструктура:** Docker, Kubernetes (K8s), Helm
* **Базы данных и обмен сообщениями:** Redis, RabbitMQ, S3 (MinIO/AWS)
* **Мониторинг:** Prometheus, Grafana
