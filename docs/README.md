# Стили LaTeX для оформления документов по ГОСТ 7.32-2017

Набор стилей LaTeX для оформления документов в соответствии с ГОСТ 7.32-2017 "Система стандартов по информации, библиотечному и издательскому делу. Отчет о научно-исследовательской работе. Структура и правила оформления".

## Быстрый старт

1. Используйте класс документа `gost-7-32.cls`:
   ```latex
   \documentclass[14pt]{gost-7-32}
   ```

2. Определите необходимые макросы для титульной страницы:
   ```latex
   \newcommand{\ministry}{МИНИСТЕРСТВО ОБРАЗОВАНИЯ И НАУКИ РОССИЙСКОЙ ФЕДЕРАЦИИ}
   \newcommand{\universityFull}{Полное название университета}
   \newcommand{\universityShort}{Сокращенное название}
   \newcommand{\department}{Название кафедры}
   \newcommand{\workType}{Отчет по лабораторной работе}
   \newcommand{\discipline}{Название дисциплины}
   \newcommand{\theme}{Тема работы}
   \newcommand{\group}{Группа}
   \newcommand{\faculty}{Факультет}
   \newcommand{\student}{ФИО студента}
   \newcommand{\supervisorDegree}{к.т.н.}
   \newcommand{\supervisor}{ФИО руководителя}
   \newcommand{\city}{Город}
   \newcommand{\docyear}{2023}
   ```

3. Создайте структуру документа:
   ```latex
   \begin{document}
   
   % Титульная страница
   \maketitlepage
   
   % Оглавление
   \tableofcontents
   \newpage
   
   % Введение
   \introduction
   Текст введения...
   
   % Основная часть
   \section{Название раздела}
   Текст раздела...
   
   % Заключение
   \conclusion
   Текст заключения...
   
   % Список литературы
   \references
   \begin{thebibliography}{99}
   \bibitem{source1} Описание источника 1.
   \end{thebibliography}
   
   \end{document}
   ```

## Состав пакета

Пакет включает следующие файлы стилей:

- `gost-7-32.cls` - основной класс документа
- `gost-7-32-headings.sty` - стиль заголовков
- `gost-7-32-toc.sty` - стиль оглавления
- `gost-7-32-lists.sty` - стиль списков
- `gost-7-32-bibliography.sty` - стиль библиографии
- `gost-7-32-captions.sty` - стиль подписей
- `gost-7-32-tables.sty` - базовый стиль таблиц
- `gost-7-32-commands.sty` - дополнительные команды
- `gost-7-32-counters.sty` - счетчики
- `gost-7-32-title-page.sty` - стиль титульной страницы
- `gost-7-32-code-style.sty` - стиль оформления кода
- `gost-7-32-graphics-style.sty` - стиль оформления графики
- `gost-7-32-table-style.sty` - расширенный стиль таблиц

## Основные команды

### Специальные разделы

- `\introduction` - создает заголовок "ВВЕДЕНИЕ"
- `\conclusion` - создает заголовок "ЗАКЛЮЧЕНИЕ"
- `\references` - создает заголовок "СПИСОК ИСПОЛЬЗОВАННЫХ ИСТОЧНИКОВ"
- `\essay` - создает заголовок "РЕФЕРАТ"
- `\definitions` - создает заголовок "ОПРЕДЕЛЕНИЯ"
- `\abbreviations` - создает заголовок "ОБОЗНАЧЕНИЯ И СОКРАЩЕНИЯ"
- `\defsabbrs` - создает заголовок "ОПРЕДЕЛЕНИЯ, ОБОЗНАЧЕНИЯ И СОКРАЩЕНИЯ"
- `\appendix{Название}` - создает заголовок приложения

### Графика

- `\imgfull{имя_файла}{подпись}` - изображение на всю ширину
- `\imgwidth{имя_файла}{подпись}{ширина}` - изображение с указанной шириной
- `\imgdouble{файл1}{файл2}{подпись1}{подпись2}{общий_заголовок}{общая_подпись}` - два изображения рядом

### Таблицы

- `\simptable{заголовок}{метка}{формат}{содержимое}` - простая таблица
- `\begin{longtab}{заголовок}{метка}{формат}{заголовки}...\end{longtab}` - длинная таблица
- `\begin{designations}...\designation{Обозначение}{Описание}...\end{designations}` - таблица обозначений

### Код

- `\begin{lstlisting}[style=pythonstyle]...\end{lstlisting}` - блок кода
- `\code{текст}` - код внутри строки
