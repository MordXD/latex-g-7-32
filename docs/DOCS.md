## Введение

Данный набор стилей предназначен для оформления документов в соответствии с ГОСТ 7.32-2017 "Система стандартов по информации, библиотечному и издательскому делу. Отчет о научно-исследовательской работе. Структура и правила оформления".

Стили обеспечивают корректное форматирование всех элементов документа: заголовков, списков, таблиц, рисунков, библиографии и т.д. в соответствии с требованиями стандарта.

## Основной класс документа

Основной класс документа `gost-7-32.cls` является базовым классом, который подключает все необходимые стили и устанавливает основные параметры форматирования.

### Использование

```latex
\documentclass[14pt]{gost-7-32}
```

### Поддерживаемые опции

- `12pt` - размер шрифта 12 пунктов
- `14pt` - размер шрифта 14 пунктов (по умолчанию)

### Основные настройки

- Формат бумаги A4
- Межстрочный интервал 1.5
- Отступ первой строки абзаца 12.5 мм
- Поля: левое - 3 см, правое - 1.5 см, верхнее и нижнее - 2 см
- Шрифт Times New Roman (через пакет tempora)
- Поддержка русского языка

## Стили оформления

### Заголовки

Файл: `gost-7-32-headings.sty`

Этот стиль определяет форматирование заголовков разделов, подразделов и пунктов, а также специальных разделов документа.

#### Основные команды

- `\section{Название}` - создает заголовок раздела
- `\subsection{Название}` - создает заголовок подраздела
- `\subsubsection{Название}` - создает заголовок пункта

#### Специальные заголовки

- `\introduction` - создает заголовок "ВВЕДЕНИЕ"
- `\conclusion` - создает заголовок "ЗАКЛЮЧЕНИЕ"
- `\references` - создает заголовок "СПИСОК ИСПОЛЬЗОВАННЫХ ИСТОЧНИКОВ"
- `\essay` - создает заголовок "РЕФЕРАТ"
- `\definitions` - создает заголовок "ОПРЕДЕЛЕНИЯ"
- `\abbreviations` - создает заголовок "ОБОЗНАЧЕНИЯ И СОКРАЩЕНИЯ"
- `\defsabbrs` - создает заголовок "ОПРЕДЕЛЕНИЯ, ОБОЗНАЧЕНИЯ И СОКРАЩЕНИЯ"
- `\selfcheckquestions` - создает заголовок "ОТВЕТЫ НА ВОПРОСЫ ДЛЯ САМОПРОВЕРКИ"

#### Приложения

- `\appendix{Название приложения}` - создает заголовок приложения с автоматической нумерацией русскими буквами

### Оглавление

Файл: `gost-7-32-toc.sty`

Этот стиль определяет форматирование оглавления в соответствии с ГОСТ.

#### Основные команды

- `\tableofcontents` - создает оглавление

#### Настройки

- Заголовок "СОДЕРЖАНИЕ" выровнен по центру и написан заглавными буквами
- Точечные лидеры между названием раздела и номером страницы
- Настроены отступы и интервалы между элементами оглавления
- Настроены гиперссылки для PDF-документа

### Списки

Файл: `gost-7-32-lists.sty`

Этот стиль определяет форматирование маркированных и нумерованных списков.

#### Настройки

- Маркированные списки первого уровня используют тире (--) в качестве маркера
- Маркированные списки второго уровня используют точку (•) в качестве маркера
- Нумерованные списки первого уровня используют арабские цифры с закрывающей скобкой (1), 2), ...)
- Нумерованные списки второго уровня используют строчные русские буквы с закрывающей скобкой (а), б), ...)
- Настроены отступы для всех уровней списков

### Библиография

Файл: `gost-7-32-bibliography.sty`

Этот стиль определяет форматирование списка литературы в соответствии с ГОСТ.

#### Основные команды

```latex
\begin{thebibliography}{99}
\bibitem{метка} Описание источника
\end{thebibliography}
```

#### Настройки

- Номера источников с точкой
- Настроены отступы и интервалы
- Локализованы названия месяцев для русского языка

### Подписи

Файл: `gost-7-32-captions.sty`

Этот стиль определяет форматирование подписей к рисункам и таблицам.

#### Настройки

- Подписи к таблицам выровнены по левому краю с тире в качестве разделителя
- Подписи к рисункам выровнены по центру с тире в качестве разделителя
- Слово "Рисунок" в подписях к рисункам

### Таблицы

Файл: `gost-7-32-tables.sty`

Этот стиль определяет базовое форматирование таблиц.

#### Новые типы колонок

- `Y` - колонка с автоматической шириной и выравниванием по центру
- `Z` - колонка с автоматической шириной и выравниванием по правому краю

#### Окружение для обозначений

```latex
\begin{designations}
\designation{Обозначение}{Описание}
\end{designations}
```

### Команды

Файл: `gost-7-32-commands.sty`

Этот стиль определяет дополнительные команды для оформления документа.

#### Основные команды

- `\keywords{текст}` - определяет ключевые слова для реферата без переносов

### Счетчики

Файл: `gost-7-32-counters.sty`

Этот стиль определяет счетчики для нумерации элементов документа.

#### Основные команды

- `\AlphRus{счетчик}` - выводит значение счетчика в виде заглавной русской буквы (А, Б, В, ...)
- `\alphRus{счетчик}` - выводит значение счетчика в виде строчной русской буквы (а, б, в, ...)

### Титульная страница

Файл: `gost-7-32-title-page.sty`

Этот стиль определяет форматирование титульной страницы.

#### Основные команды

- `\maketitlepage` - создает титульную страницу

#### Необходимые макросы

Перед использованием команды `\maketitlepage` необходимо определить следующие макросы:

```latex
\newcommand{\ministry}{Название министерства}
\newcommand{\universityFull}{Полное название университета}
\newcommand{\universityShort}{Сокращенное название университета}
\newcommand{\department}{Название кафедры}
\newcommand{\workType}{Тип работы}
\newcommand{\discipline}{Название дисциплины}
\newcommand{\theme}{Тема работы}
\newcommand{\group}{Номер группы}
\newcommand{\faculty}{Название факультета}
\newcommand{\student}{ФИО студента}
\newcommand{\supervisorDegree}{Ученая степень руководителя}
\newcommand{\supervisor}{ФИО руководителя}
\newcommand{\city}{Город}
\newcommand{\docyear}{Год}
```

### Оформление кода

Файл: `gost-7-32-code-style.sty`

Этот стиль определяет форматирование программного кода в соответствии с ГОСТ.

#### Основные команды и окружения

- `\code{текст}` - форматирует текст как код внутри строки
- `\begin{lstlisting}...\end{lstlisting}` - окружение для блока кода
- `\lstinputlisting[опции]{путь_к_файлу}` - вставляет код из файла

#### Предопределенные стили

- `pythonstyle` - стиль для Python
- `cppstyle` - стиль для C++
- `csharpstyle` - стиль для C#
- `javastyle` - стиль для Java

#### Пример использования

```latex
\begin{lstlisting}[style=pythonstyle, caption={Пример кода на Python}]
def hello_world():
    print("Hello, World!")
\end{lstlisting}
```

### Оформление графики

Файл: `gost-7-32-graphics-style.sty`

Этот стиль определяет форматирование графических элементов в соответствии с ГОСТ.

#### Основные команды

- `\imgfull[опции]{имя_файла}{подпись}` - вставляет изображение на всю ширину текста
- `\imgwidth[опции]{имя_файла}{подпись}{ширина}` - вставляет изображение с указанной шириной (доля от ширины текста)
- `\imgheight[опции]{имя_файла}{подпись}{высота}` - вставляет изображение с указанной высотой (доля от высоты текста)
- `\imgdouble{имя_файла1}{имя_файла2}{подпись1}{подпись2}{общий_заголовок}{общая_подпись}` - вставляет два изображения рядом
- `\imgquad{имя_файла1}{имя_файла2}{имя_файла3}{имя_файла4}{подпись1}{подпись2}{подпись3}{подпись4}{общая_подпись}` - вставляет четыре изображения в виде сетки 2×2

#### Настройки

- Путь к директории с изображениями: `images/`
- Подписи к рисункам выровнены по центру
- Настроены отступы и интервалы

### Расширенное оформление таблиц

Файл: `gost-7-32-table-style.sty`

Этот стиль предоставляет расширенные возможности для оформления таблиц в соответствии с ГОСТ.

#### Основные команды и окружения

- `\simptable{заголовок}{метка}{формат_колонок}{содержимое}` - создает простую таблицу
- `\begin{widetable}{заголовок}{метка}{формат_колонок}{заголовки_колонок}...\end{widetable}` - создает таблицу на всю ширину текста
- `\begin{longtab}{заголовок}{метка}{формат_колонок}{заголовки_колонок}...\end{longtab}` - создает длинную таблицу с переносом на следующую страницу
- `\begin{zebratable}{заголовок}{метка}{формат_колонок}{заголовки_колонок}...\end{zebratable}` - создает таблицу с чередующимися цветами строк

#### Новые типы колонок

- `L{ширина}` - колонка с указанной шириной и выравниванием по левому краю
- `C{ширина}` - колонка с указанной шириной и выравниванием по центру
- `R{ширина}` - колонка с указанной шириной и выравниванием по правому краю

#### Дополнительные команды

- `\gostrothead{текст}` - создает заголовок колонки с поворотом на 90 градусов
- `\shorthead{текст}` - создает краткий заголовок колонки
- `\headcell{текст}` - создает заголовок с цветом фона

## Примеры использования

### Минимальный шаблон документа

```latex
\documentclass[14pt]{gost-7-32}

% Определяем макросы для титульной страницы
\newcommand{\ministry}{МИНИСТЕРСТВО ОБРАЗОВАНИЯ И НАУКИ РОССИЙСКОЙ ФЕДЕРАЦИИ}
\newcommand{\universityFull}{Полное название университета}
\newcommand{\universityShort}{Сокращенное название}
\newcommand{\department}{Название кафедры}
\newcommand{\workType}{Отчет по лабораторной работе}
\newcommand{\discipline}{Название дисциплины}
\newcommand{\theme}{Тема работы}
\newcommand{\group}{Группа}
\newcommand{\faculty}{Факультет}
\newcommand{\student}{ФИО студента}
\newcommand{\supervisorDegree}{к.т.н.}
\newcommand{\supervisor}{ФИО руководителя}
\newcommand{\city}{Город}
\newcommand{\docyear}{2023}

\begin{document}

% Титульная страница
\maketitlepage

% Оглавление
\tableofcontents
\newpage

% Введение
\introduction
Текст введения...

% Основная часть
\section{Название раздела}
Текст раздела...

\subsection{Название подраздела}
Текст подраздела...

% Заключение
\conclusion
Текст заключения...

% Список литературы
\references
\begin{thebibliography}{99}
\bibitem{source1} Описание источника 1.
\bibitem{source2} Описание источника 2.
\end{thebibliography}

% Приложение
\appendix{Название приложения}
Текст приложения...

\end{document}
```

## Часто задаваемые вопросы

### Как изменить размер шрифта?

Размер шрифта задается при подключении класса документа:

```latex
\documentclass[12pt]{gost-7-32} % 12pt или 14pt
```

### Как добавить нестандартный раздел?

Для создания нестандартного раздела можно использовать команду `\section*{}` с ручным добавлением в оглавление:

```latex
\section*{Нестандартный раздел}
\addcontentsline{toc}{section}{НЕСТАНДАРТНЫЙ РАЗДЕЛ}
```

### Как изменить нумерацию страниц?

Для изменения нумерации страниц можно использовать команду `\pagenumbering{}`:

```latex
\pagenumbering{roman} % Римские цифры (i, ii, iii, ...)
\pagenumbering{arabic} % Арабские цифры (1, 2, 3, ...)
```

### Как добавить библиографию из BibTeX?

Для использования BibTeX необходимо:

1. Создать файл с расширением `.bib` (например, `sources.bib`)
2. Добавить в него библиографические записи
3. В документе использовать команды:

```latex
\references
\bibliographystyle{gost} % Требуется установка пакета biblatex-gost
\bibliography{sources}
```
