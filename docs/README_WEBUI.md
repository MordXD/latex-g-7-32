# LaTeX Editor WebUI - GOST 7.32

Современный веб-интерфейс для редактирования LaTeX документов с автоматической компиляцией в PDF.

## Возможности

✨ **Основные функции:**
- Редактирование LaTeX кода в реальном времени
- Автоматическое сохранение изменений
- Мгновенная компиляция при изменении файла
- Предварительный просмотр PDF справа
- Изменяемый размер панелей
- Современный минималистичный дизайн

🎯 **Удобство использования:**
- Горячие клавиши (Ctrl+S для сохранения, Ctrl+Enter для компиляции)
- Индикатор статуса компиляции
- Уведомления о результатах операций
- Счетчик символов и строк
- Отображение позиции курсора
- Поддержка табуляции в редакторе

## Установка и запуск

### 1. Установка зависимостей

```bash
pip install -r requirements.txt
```

### 2. Запуск приложения

```bash
python app.py
```

### 3. Открытие в браузере

Перейдите по адресу: http://localhost:5000

## Требования

- Python 3.7+
- LaTeX дистрибутив (TeX Live, MiKTeX)
- Команда `pdflatex` должна быть доступна в PATH

## Использование

### Редактирование
- Код LaTeX отображается в левой панели
- Изменения автоматически сохраняются через 2 секунды
- PDF обновляется автоматически при изменении файла

### Горячие клавиши
- `Ctrl + S` - Сохранить файл
- `Ctrl + Enter` - Компилировать LaTeX
- `Tab` - Вставить отступ (4 пробела)

### Кнопки интерфейса
- **Сохранить** - Принудительное сохранение файла
- **Компилировать** - Ручная компиляция LaTeX
- **Обновить PDF** - Перезагрузить PDF просмотр
- **Скачать PDF** - Скачать готовый PDF файл
- **Перенос строк** - Включить/отключить перенос длинных строк

### Изменение размера панелей
Перетащите разделитель между панелями для изменения их размера.

## Технические детали

### Архитектура
- **Backend**: Flask + SocketIO для real-time обновлений
- **Frontend**: Vanilla JavaScript с WebSocket подключением
- **Компиляция**: pdflatex через subprocess
- **Мониторинг файлов**: watchdog для отслеживания изменений

### Автоматическая компиляция
Приложение отслеживает изменения в `main.tex` и автоматически запускает компиляцию. Результат отображается в правой панели через iframe.

### Обработка ошибок
- Ошибки компиляции отображаются в уведомлениях
- Статус операций показывается в индикаторе
- Логирование всех операций в консоль

## Настройка

### Изменение порта
В файле `app.py` измените строку:
```python
socketio.run(app, debug=True, host='0.0.0.0', port=5000)
```

### Настройка автосохранения
В файле `static/js/app.js` измените таймаут:
```javascript
this.saveTimeout = setTimeout(() => {
    this.saveFile();
}, 2000); // Время в миллисекундах
```

## Устранение неполадок

### LaTeX не компилируется
1. Убедитесь, что установлен LaTeX дистрибутив
2. Проверьте доступность команды `pdflatex` в терминале
3. Проверьте права доступа к файлам

### PDF не отображается
1. Убедитесь, что файл `main.pdf` создается
2. Проверьте консоль браузера на ошибки
3. Попробуйте обновить страницу

### Проблемы с подключением
1. Проверьте, что Flask сервер запущен
2. Убедитесь, что порт 5000 не занят
3. Проверьте настройки брандмауэра
